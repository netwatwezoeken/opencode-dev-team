# Suggested Commands

- Full tests: `npx vitest run`
- Focused tests: `npx vitest run src/<name>.test.ts`
- Typecheck: `npx tsc --noEmit`
- Lint: inspect repository ESLint configuration and run `npx eslint .` when applicable.
- Format check: `npx prettier --check .`; format changed files with `npx prettier --write <files>`.
- Git inspection: `git status --short --branch`, `git diff`, `git log --oneline -10`.
